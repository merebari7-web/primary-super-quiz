# Primary Super Quiz

Free, classroom-ready practice for **English-medium primary learning** (Primary 1–6, about ages 6–12). Designed around the Nigerian primary classroom — 16 subjects × 6 classes × 100 questions = **9,600** multiple-choice items — and usable anywhere similar topics are taught.

**Live site:** [https://merebari7-web.github.io/primary-super-quiz/](https://merebari7-web.github.io/primary-super-quiz/)

This is **independent practice**, not an official NERDC, ministry or common-entrance paper. Practice grades (A–E) are for learning conversations only.

## Why teachers use it

- **Retrieval practice** with explanations (Practice mode) or a paper-like wait (Exam mode)
- **Printable** 80-question exam with answer key, plus homework from missed items
- **Learning report** with strengths, gaps and a recommended next step
- **Works offline** after the first visit — useful where connectivity is weak
- **No ads**, no pupil server, no account required for younger children
- **Accessibility:** larger text, high contrast, read aloud, keyboard, reduce motion

See **For teachers**, **For families**, **Why it works** and **Accessibility** on the live site.

## Subjects

| Group | Subjects |
|---|---|
| Core | English Language, Mathematics, Basic Science, Social Studies, Civic Education |
| Practical | Computer Studies, Agricultural Science, Cultural & Creative Arts, PHE, Home Economics |
| Reasoning | Verbal Reasoning, Quantitative Reasoning |
| Humanities | History, Security Education |
| Religion | Christian Religious Studies (CRS), Islamic Religious Studies (IRS) |

Pupils can sit 10, 20, 50 or the full 100 questions.

## Features

- Practice, Exam and Timed modes; Daily Challenge; Smart Practice; Lightning 5
- Instant explanations, hint / 50-50 / skip, flag-for-review
- A–E practice grades, XP and badges saved **on this device**
- Sibling profiles, favourite subjects, quiz clock
- Printable certificate (independent practice, not a qualification)
- Optional Google Sign-In; guest play always works
- PWA: install to the home screen

## Run locally

```bash
python3 -m http.server 8080
```

Open `http://localhost:8080`.
